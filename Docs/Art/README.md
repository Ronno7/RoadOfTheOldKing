# Art

Current state: the tutorial world has the animated player, follow camera and hatchet pickup/carrying. Four-direction sprint, dash, opening strike, stationary throw/aim and catch run in live Tutorial gameplay; see the [player milestone gallery](Player/README.md). Current player art is accepted; future animation is incremental alongside Tutorial gameplay. The [development plan](../VerticalSlice.md) tracks slice milestones and deferred work; the [tutorial plan](Tutorial/Plan.md) owns world layout and art decisions.

To build a scene with the existing kits, follow the [tutorial scene quick start](Tutorial/QuickStart.md).
