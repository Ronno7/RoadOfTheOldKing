# Animation assets

Playback definitions are grouped by character, separately from the sprite textures under `Assets/Art/Sprites`.

| Folder | Contents |
| --- | --- |
| Player | `PlayerAnimationSet` and one `DirectionalSpriteAnimation` per filled slot, generated by **Road of the Old King > Animation Import > Player** |
| Enemies | `Wolf.asset` (`PredatorAnimationSet`) and its clips in `Enemies/Wolf/`, imported with **Animation Import > Wolf**; Lowlands characters have their own `AnimationSet.asset` and clips under `Enemies/<Character>/`, imported with **Animation Import**, selecting the named character |
| NPCs | `TravelingTrader/AnimationSet.asset` (`NpcAnimationSet`) and its standing, idle and walk clips, imported with **Road of the Old King > Animation Import > Traveling Trader** |

Importers create and assign these assets; playback rate, looping and contact frames are edited on each asset and survive re-imports. Gameplay-driven presenters sample them, so gameplay never waits on animation.

See [player animation](../../../Docs/PlayerAnimation.md) for the state slots and playback rules.
