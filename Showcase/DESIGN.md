# Showcase design

The site lives in `Showcase/Showcase/`. The authoritative design brief is [DESIGN.md](Showcase/DESIGN.md).

From the repository root, run `python -m http.server 8000 --directory Showcase/Showcase`, then open `http://localhost:8000/`. From this outer folder, use `--directory Showcase`.

The site is a draft, published on GitHub Pages at https://ronno7.github.io/RoadOfTheOldKing/ (owner, 23 Nov) and linked from the README.
